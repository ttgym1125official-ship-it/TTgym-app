# プライベートジム貸切 一式

| 何 | どこ |
|---|---|
| LP（ランディングページ） | `public/space/index.html` → 公開URL `https://<アプリのドメイン>/space` |
| SNSでリンクを貼った時の画像 | `public/space/og.png`（作り直し: `node scripts/render-space-og.mjs`） |
| LPの写真・動画 | `public/space/img/`（`hero.mp4` が一番上の背景動画） |
| LINE自動返信 | `api/line-webhook.js` の `spaceRentalReply` |
| SNS投稿ネタ・台本 | [sns.md](./sns.md) |
| LINE手動返信テンプレ | [line-templates.md](./line-templates.md) |

## 仕組み

```
X / Threads / TikTok の投稿・プロフィール
        │  リンク: https://<ドメイン>/space?from=x  （threads / tiktok）
        ▼
       LP  ──「LINEで空きを確認する」
        │  公式LINEのトークが「貸切予約／希望日／時間…／きっかけ：X」入力済みで開く
        ▼
   公式LINE ── 自動返信（未記入ならフォーム、記入済みなら「確認して折り返します」）
        │
        ▼
 スタッフがLINEチャットで空き確認 → 確定・決済案内（line-templates.md をコピペ）
```

`?from=x` を付けておくと予約メッセージに「きっかけ：X」が入るので、どのSNSが効いているか分かります。

## 公開前に必ずやること（チェックリスト）

- [ ] `public/space/index.html` 上部の `id="config"` を書き換え
  - `data-line-id` … 公式LINEのベーシックID（`@`から始まる）
  - `data-line-url` … 友だち追加URL（`https://lin.ee/…`）
  - `data-address` … 「〇〇駅 徒歩〇分」など
- [ ] **LPの「でも、思いきり動きたい」の写真（`img/people.jpg`）に写っている方に、LP掲載のOKをもらう**（顔が写っています。NGなら `img/wide.jpg` などに差し替え）
- [ ] 営業日を決める（LPは「9:00〜14:00」とだけ書いていて、曜日は書いていません）
- [ ] 決済方法を決める（PayPay／銀行振込／Square決済リンクなど）→ line-templates.md の「確定」テンプレに入れる
- [ ] 公開後、スマホで `/space` を開いて「LINEで空きを確認する」を押し、トークが開くか確認
- [ ] LINEで「貸切予約」と送って自動返信が来るか確認

## 決めておきたい運用ルール（LPに書いた内容）

- 料金：貸切スタンダード ¥5,000/h（撮影不可）／貸切＋撮影 ¥35,000/h／最大8名まで同料金
- レンタル：グローブ・ミット 1回 ¥2,000
- 撮影：写真・動画すべて不可（スマホのフォーム確認動画も不可）。無断撮影は撮影プランとの差額を請求
- 清掃：使った器具は必ずアルコールで清掃（次の利用者と入れ替わりで重なることがある）
- 片付け：器具は元の場所に戻す
- 時間：9:00〜14:00、準備・片付け・清掃込み。最終スタート 13:00
- キャンセル：前日まで無料／当日・無断は100%
- 支払い：事前決済
- ケガは自己責任、破損は実費

**事前決済を強く推奨します。** 当日キャンセル料は後から請求しても回収しづらいので、確定時に払ってもらうのが一番トラブルが少ないです。

**撮影禁止は「受付時に一言＋張り紙」まで徹底すると効きます。** 「撮影は撮影プランのみなのでスマホはしまっておいてくださいね」と最初に言っておけば、ほぼ守られます。

## 「密かに」集める設定について

LPには `noindex`（Google検索に載せない）を入れています。SNSから来た人だけが見られる状態です。検索からも集客したくなったら、`index.html` の `<meta name="robots" content="noindex" />` の1行を消してください。

## 予約管理

最初はGoogleカレンダーに「貸切 11-13 山田様 4名 ミット有 済」のように入れるだけで十分です。
パーソナルの予約と同じカレンダーにすると、ダブルブッキングを防げます。
