# 公式LINE 返信テンプレート

「貸切予約」を含むメッセージには自動返信が出ます（`api/line-webhook.js`）。
そのあとの空き確認〜確定はスタッフがLINEチャットから手動で返します。以下をコピペして使ってください。
LINE Official Account Manager →「チャット」→「定型文」に登録しておくと速いです。

---

## ① 空きあり → 確定案内

```
ご連絡ありがとうございます！
下記の内容で貸切のご予約が可能です。

📅 〇/〇（〇）〇:〇〇〜〇:〇〇（〇時間）
👥 〇名
💰 貸切スタンダード ¥5,000 × 〇時間 = ¥〇,〇〇〇
🥊 グローブ・ミット ¥2,000（ご希望の場合）

▼お支払い（事前決済）
【ここに決済方法：PayPay ID／振込先／決済リンクなど】

お支払いの確認をもって予約確定となります。
〇/〇（〇）〇:〇〇までにお願いいたします。

▼ご確認ください
・写真・動画の撮影はできません（スマホ含む）
・使った器具はアルコールで清掃、元の場所に戻してください
・準備、片付けも利用時間内でお願いします
・前日まで無料キャンセル／当日キャンセルは100%
```

## ② 空きなし → 代替案

```
ご連絡ありがとうございます！
あいにくその時間は埋まっておりまして…🙇
近い時間だと下記が空いています。

・〇/〇（〇）〇:〇〇〜〇:〇〇
・〇/〇（〇）〇:〇〇〜〇:〇〇

いかがでしょうか？
```

## ③ 入金確認 → 予約確定

```
お支払いを確認しました。ご予約確定です！

📅 〇/〇（〇）〇:〇〇〜〇:〇〇
📍 【住所】
（【目印・入り方：〇階／インターホンなど】）

当日は受付でお名前をお伝えください。
お待ちしております🥊
```

## ④ 前日リマインド

```
明日の貸切ご予約のご確認です。

📅 〇/〇（〇）〇:〇〇〜〇:〇〇
📍 【住所】

持ち物：室内シューズ（裸足OK）／タオル／飲み物
※使った器具はアルコールで清掃、元の場所に戻してください
※撮影はできませんのでご了承ください

お気をつけてお越しください！
```

## ⑤ 撮影プランの問い合わせ

```
撮影プランのお問い合わせありがとうございます！
料金は貸切＋撮影で1時間 ¥35,000 です（最大8名）。

他のお客様が映り込まないよう時間を調整するため、
下記を教えていただけますか？

・撮影内容（例：SNS用のトレーニング動画／商品撮影 など）
・人数（撮影スタッフ含む）
・機材（三脚・照明など）
・公開先（SNS／広告／その他）
・ご希望の日時
```

## ⑥ 撮影しているのを見つけたとき（口頭でもOK）

```
恐れ入ります、スタンダードプランでは撮影をご遠慮いただいております。
撮影をご希望の場合は撮影プラン（¥35,000/h）への切り替えとなりますが、いかがされますか？
```
