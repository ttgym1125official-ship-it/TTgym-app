# SNS運用キット（X / Threads / TikTok）

## リンクの貼り方

| SNS | プロフィールに貼るURL |
|---|---|
| X | `https://<ドメイン>/space?from=x` |
| Threads | `https://<ドメイン>/space?from=threads` |
| TikTok | `https://<ドメイン>/space?from=tiktok` |

予約メッセージに「きっかけ：X」などが自動で入るので、どこから予約が来たか数えられます。

> **X・Threadsは本文にリンクを入れると表示が伸びにくい**ので、本文は「詳細はプロフのリンク／リプ欄へ」とし、リンクは自分のリプライかプロフィールに置くのがおすすめです。

## プロフィール文

**X / Threads**
```
都内パーソナルジムTTGYM｜キックボクシングエリアを昼だけ時間貸し🥊
10:00〜14:00／1時間¥3,000／会員登録不要
自主練・ミット・出張パーソナルに
予約はLINEから👇
```

**TikTok**
```
ジムの空き時間、貸してます🥊
1時間3,000円｜10-14時限定
予約は🔗のLINEから
```
（「都内」は実際の地域に変えてください。地名が入ると近所の人に刺さります）

## 投稿の基本方針

- **ターゲットは3つ**：①キック・ボクシングの自主練勢 ②フリーのパーソナルトレーナー ③ミット練習したい2人組
- **刺さる言葉**：「サンドバッグ叩き放題」「1人でも2人でも同料金」「入会金なし」「昼だけ」「少枠」
- **撮影禁止は隠さず先に言う**：「撮影NGだからこそ人目を気にせず練習できる」とメリットとして伝える
- **頻度目安**：X・Threads 1日1〜2投稿、TikTok 週3本
- お客様の撮影は禁止ですが、**ジム側が無人のエリアを撮るのはOK**。素材は空のエリア・サンドバッグ・マット・時計（10:00）など

## TikTok 台本（15〜30秒・5本）

人物を映さずに撮れるものだけにしています。

**① 「この場所、1時間3,000円です」**
- 0-2秒：入口からキックエリアへ歩いて入る（手持ち・POV）
- テロップ：「この場所、1時間3,000円で借りれます」
- 2-10秒：サンドバッグ → マット → 全体をゆっくり見せる
- テロップ：「サンドバッグ叩き放題／1人でも2人でも同料金」
- 10-15秒：時計の10:00 → 14:00
- テロップ：「昼の10〜14時だけ。予約はプロフのLINEから」
- 音源：トレンドのビート系

**② 「サンドバッグの音だけ」ASMR**
- スタッフが手元だけ映してサンドバッグを打つ（顔なし）
- テロップ：「この音、昼なら1時間3,000円で出し放題」

**③ 「1日4枠しかない理由」**
- 時計の早送り映像
- テロップ：「10時〜14時だけ」「パーソナルの合間だけ貸してるから」「1日4枠」「だから先着順です」

**④ 「撮影禁止にしてる理由」**
- 空のエリア＋スマホに✕のテロップ
- テロップ：「スペースレンタル、撮影禁止です」「会員さんのプライバシーを守るため」「人目を気にせず練習できる場所にしたい」
- ※この動画を撮るのはジム側なのでOK

**⑤ 「トレーナーさんへ」**
- ミット・グローブを並べる映像
- テロップ：「フリーのトレーナーさん」「セッション場所に困ってませんか？」「キックもミットもOK／1時間3,000円」
