# SNS運用キット（X / Threads / TikTok）

## リンクの貼り方

| SNS | プロフィールに貼るURL |
|---|---|
| X | `https://<ドメイン>/space?from=x` |
| Threads | `https://<ドメイン>/space?from=threads` |
| TikTok | `https://<ドメイン>/space?from=tiktok` |

予約メッセージに「きっかけ：X」などが自動で入るので、どこから予約が来たか数えられます。

> **X・Threadsは本文にリンクを入れると表示が伸びにくい**ので、本文は「詳細はプロフのリンクから」とし、リンクはプロフィールか自分のリプライに置くのがおすすめです。

## 投稿の基本方針

- **ターゲット**：①友達・仲間と思いきり動きたいグループ ②フリーのパーソナルトレーナー ③チーム・サークルの練習 ④人目を気にせず1人で追い込みたい人
- **刺さる言葉**：「ジム丸ごと貸切」「8人で割ると1人625円」「サンドバッグ・バトルロープ」「入会金なし」「1日5枠」
- **撮影禁止は隠さず先に言う**：「撮影NGだから、人目もカメラも気にせず動ける」とメリットとして伝える
- **頻度目安**：X・Threads 1日1〜2投稿、TikTok 週3本
- お客様の撮影は禁止ですが、**ジム側が無人のフロアを撮るのはOK**。今回の動画（暗いフロアをゆっくり見せるもの）はそのままTikTokに使えます

## TikTok 台本（15〜20秒・5本）

人物を映さずに撮れるものだけです。

**① 「このジム、1時間5,000円で貸切できます」**（今回の動画をそのまま使える）
- 0-3秒：暗いフロアを入口からゆっくりパン
- テロップ：「このジム、1時間5,000円で貸切できます」
- 3-10秒：サンドバッグ → バトルロープ
- テロップ：「サンドバッグ・バトルロープあり／8人まで同料金」
- 10-15秒：フロア全体
- テロップ：「9〜14時限定。予約はプロフのLINEから」
- 音源：トレンドのビート系

**② 「8人で割ったら1人625円」**
- フロア全体の映像に計算テロップ「5,000円 ÷ 8人 = 625円」「カラオケより安い」

**③ 「サンドバッグの音だけ」ASMR**
- スタッフが手元だけ映してサンドバッグを打つ（顔なし）
- テロップ：「この音、1時間5,000円で出し放題」

**④ 「撮影禁止にしてる理由」**
- 暗いフロア＋スマホに✕のテロップ
- テロップ：「この貸切ジム、撮影禁止です」「会員さんのプライバシーを守るため」「カメラを気にせず動ける場所にしたい」
- ※この動画を撮るのはジム側なのでOK

**⑤ 「トレーナーさんへ」**
- ミット・グローブを並べる映像
- テロップ：「フリーのトレーナーさん」「セッション場所に困ってませんか？」「ジム貸切 1時間5,000円」
