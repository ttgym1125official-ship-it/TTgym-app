# TTGYM 健康ダッシュボード（公式LINE版）セットアップ

公式LINEに食事の写真か「昼食 牛丼並と味噌汁」のような文章を送ると、AIが品目ごとに重さを見積もって栄養（カロリー・PFC・36項目）を計算し、LINEに返信します。記録はLINE内で開くダッシュボード（LIFF）で確認できます。

| 場所 | 中身 |
| --- | --- |
| `api/line-webhook.js` | 食事・訂正・体重の受け取りと返信、友だち追加時のあいさつ（既存のアプリ連携・Q&Aはそのまま） |
| `api/_lib/nutri.js` | AI解析（Claude）、データ保存、返信文の組み立て |
| `api/nutrition.js` | ダッシュボード用のデータAPI（LINEのアクセストークンで本人確認） |
| `src/liff/` | ダッシュボード（`/liff`：今日・履歴・目標）、目標設定（`/liff/goal`）、プロフィール登録（`/liff/profile`） |
| `src/storeMenu.js` | チェーン店メニューのPFC（アプリの食事タブと共通） |
| `src/membership.js` | メンバーシップのランクとポイント計算（アプリと共通） |
| `src/liff/nutrients.js` | 36項目の栄養素の説明文・目標値の計算式・判定ルール |
| `scripts/render-rich-menu.mjs` / `setup-rich-menu.mjs` | リッチメニュー（2ページ・タブ切り替え）の画像作成と登録 |

## デモ表示（設定前でも見られます）

`https://t-tgym-app.vercel.app/liff?demo=1` を開くと、サンプルデータで画面を確認できます。

## 本番の設定手順

### 1. LIFFアプリを作る（LINE Developers）

1. [LINE Developers](https://developers.line.biz/console/) で、公式LINE（Messaging APIチャネル）と**同じプロバイダー**を開く
2. 「新規チャネル作成」→「LINEログイン」を作成（アプリタイプは「ウェブアプリ」）
3. 作ったチャネルの「LIFF」タブ →「追加」
   - サイズ: **Full**
   - エンドポイントURL: `https://t-tgym-app.vercel.app/liff`
   - Scope: `profile`
   - 友だち追加オプション: On（Aggressive）
4. 表示された **LIFF ID**（例 `2000000000-AbCdEfGh`）と、チャネル基本設定の **チャネルID** を控える
5. チャネルを「公開済み」にする

### 2. Vercel の環境変数を追加

LIFF ID（`2012240533-jEmcXBvp`）とチャネルID（`2012240533`）は `src/lineConfig.js` に書いてあるので、設定は不要です（環境変数 `VITE_LIFF_ID` / `LIFF_ID` / `LINE_LOGIN_CHANNEL_ID` があればそちらが優先）。

追加が必要なのは次の1つだけです。設定したら再デプロイ（Redeploy）してください。

| 名前 | 値 |
| --- | --- |
| `ADMIN_API_KEY` | 自分で決めた長めの文字列（管理画面からLINEを送る・リッチメニューを登録するためのキー） |

`ANTHROPIC_API_KEY`・`LINE_CHANNEL_SECRET`・`LINE_CHANNEL_ACCESS_TOKEN` は既存のものを使います。

食事記録・AI返信・あいさつを一時的に止めたいときは、`LINE_NUTRITION_OFF=1` を設定して再デプロイすると、今までどおりの動きに戻ります。

### 3. リッチメニューを登録

管理画面（`/admin`）→「公式LINE」→「LINE操作キー」に `ADMIN_API_KEY` と同じ文字列を入れて保存 →「リッチメニュー」を開いてリンクを入れ（空欄でもOK）、「LINEに登録する」を押します。
（GitHub Actions の「Set up LINE rich menu」を実行しても同じことができます。リポジトリの Secrets の `CRON_SECRET` を使い、リンクは管理画面で前回登録したものを使います）

リッチメニューは上のタブで「メインメニュー」と「サポートメニュー」を切り替える2ページ構成です。

| ページ | タイル | 開く先（すべてLINEの中で開くページ） |
| --- | --- | --- |
| メイン | 今日の栄養 | ダッシュボード（`/liff`） |
| メイン | 目標設定・MY成長・測定結果 | タブで「目標・成長・測定・レポート・コメント」（`/liff/goal`。以前の `/liff/growth` もここ） |
| メイン | 予約 | 予約リンク（空欄なら「予約」とメッセージ送信） |
| メイン | 体調・トレーニング自己管理 | 体調管理・トレーニング（`/liff/condition`） |
| メイン | オンライントレーニングサポート | 配信・2週間食事プログラム・目的別トレーニングプログラム（`/liff/online`） |
| サポート | レシピ・おすすめ店 | 週刊レシピ・おすすめのお店・外食のおすすめメニュー（`/liff/recipe`） |
| サポート | TTGYMオススメ健康アイテム | 管理画面で登録したアイテムとサプリメントの目安（`/liff/items`） |
| サポート | ビフォーアフター | TTGYMのビフォーアフターのページ（https://claude.ai/artifact/PALnehkVe6vqe72S7kkVz6）を直接開く |
| サポート | オススメ健康ショップ | リンク |
| サポート | TEAM TOPメンバー参加申込み | リンク |

おすすめのお店は `src/liff/content/stores.js`（①〜⑨と表紙、写真は `public/liff/stores/`）と、管理画面の「公式LINE」→「おすすめのお店」で追加したお店（`global:recommendedStores`）。
健康アイテムは管理画面の「公式LINE」→「TTGYMオススメ健康アイテム」で追加します（`global:recommendedItems`）。
体調・トレーニング・成長・レポート・コメントの画面は `src/liff/Care.jsx`（アプリと同じ項目・判定を `src/careData.js` で共有し、見た目はダッシュボードに合わせて作り直したもの）。アプリと同じ記録（`data:<会員ID>:<項目>`）を読み書きします。アプリ未連携の人は `data:line_<LINEユーザーID>:<項目>` に保存し、アプリと連携した時点で会員側へ移します。
食事プログラム・トレーニングプログラムの内容は `src/liff/content/` にあります。
レポート（`src/liff/Report.jsx`）は「目標設定・MY成長・測定結果」のレポートタブに出ます。LINEで送った食事・水分・体重と、体調・トレーニング・成長・月次測定・パーソナルの記録を1週間／1ヶ月でまとめてグラフにします。

画像を変えたいときは `scripts/render-rich-menu.mjs` を編集して `node scripts/render-rich-menu.mjs` で作り直し、`api/_lib/richmenuAuto.js` の `RICHMENU_VERSION` を上げます。本番に反映されたあと、公式LINEに最初のメッセージが届いたときに、サーバーが自動で新しいメニューに入れ替えます（管理画面のボタンで今すぐ入れ替えることもできます）。

### 4. LINE Official Account Manager の設定

- 設定 → 応答設定: **Webhook オン**、応答メッセージ オフ（既存の設定のまま）
- あいさつメッセージ: **オフ**（友だち追加時のあいさつはWebhookから送るため。二重になるのを防ぎます）

## 動き

- **食事の写真 / 文章** → 品目ごとに記録して、今日の累計・不足しそうな栄養素・次の食事の提案を返信
- **「エビじゃなくてイカ」「ご飯は半分」** → 直前の食事を直して記録し直す
- **「体重 64.5」「体脂肪 15%」、体重計・体組成計の写真** → 体組成として記録
- **「水 500ml」「お水 1.5L」「水 コップ2杯」** → 水分として記録
- 写真は長辺1568pxのJPEGに縮めてからAIに送ります（`sharp`）。大きい写真でも読み取れます
- AIの解析に失敗したときは、別の呼び出し方で1回やり直します。それでも失敗した場合は、原因を管理画面の「LINEのやりとり」に「エラー: …」として残します
- それ以外の雑談・質問 → アプリ連携済みの人は既存のQ&A、未連携の人にはAIが短く返事（予約・料金などは「スタッフから改めて連絡」と返す）

## ダッシュボードでできること

- 食事の追加：「お店から選ぶ」（チェーン店メニュー）か「自分で入力」（メニュー名とPFC）。ビタミン・ミネラルはAIが名前とPFCから見積もります
- 水分：+200 / +350 / +500ml（目安は体重×35ml）
- 目標タブ：目標のコメント、目標体重・体脂肪率、ビフォーアフター写真、メンバーシップ（ランク・ポイント）
  - TTGYMアプリと連携済みの人は、目標と写真をアプリと共有し、ポイントもアプリと同じ記録から計算します
  - LINEだけの人は、体組成を記録した月を「月次測定」として数えます

## TTGYMアプリとの連携

公式LINE（`line_user:<LINEユーザーID>`）とアプリの会員（`profile:<ID>`）がつながっていると、次のように同じデータを使います。

| 項目 | 動き |
| --- | --- |
| 食事 | LINE・ダッシュボードで記録した食事をアプリの食事タブにも書き写す（IDが `line-` 始まり）。アプリで記録した食事はダッシュボードにも表示（「アプリで記録」） |
| 体重・体脂肪率 | アプリの成長タブ（growth）を共通で使う。LINEの「体重 64.5」や体重計の写真も成長タブに入る |
| 水分 | アプリの水分記録（water）を共通で使う |
| 目標・ビフォーアフター | アプリの登録タブと共通 |
| メンバーシップ | アプリと同じ記録・同じ式でポイントを計算 |
| プロフィール登録 | アプリの生年月日・最新の体重から初期値を入れる |

スタッフの管理画面（`/admin`）にも、LINEで記録した食事・体重・水分が表示されます。

**連携のしかた**（どちらでもOK）

- アプリの「設定」に出る6文字のコードをLINEに送る（従来どおり）
- リッチメニュー、またはダッシュボードの「目標」タブからアプリを開き、会員登録（登録済みなら「登録済みの方はこちら」）をする → 自動で連携

以前のリッチメニューのリンク（`/liff/open?tab=…`）は、アプリではなく上のLINE内のページへ転送します（リッチメニューを作り直す前でも新しいページが開きます）。

## 管理画面（/admin）での公式LINE

管理画面のいちばん上に「公式LINE」欄があります。

- 公式LINEで記録しているお客様の一覧：LINEの名前・アイコン、最終メッセージ、今日のカロリー、アプリ連携の有無、ブロック中かどうか
- お客様ごとの詳細：プロフィールと目標、今日の栄養と不足しがちな栄養素、最近の食事（品目つき）、体重、水分、LINEのやりとり（直近100件）
- **LINEでメッセージを送る**（送信した内容はやりとりに残ります）
- **アプリ会員と連携 / 解除**：連携すると、LINEだけで付けていた記録もアプリ側に移ります
- 会員詳細にも「公式LINE」欄を追加：その会員のLINEのやりとりと、メッセージ送信
- トレーナーコメントを投稿するときに「公式LINEにも送る」（連携済みの会員だけ。初期はオン）
- 会員一覧に、LINE連携済みの印
- 会員の食事記録に、LINEで記録したものは「LINE」の印
- 週刊レシピのLINE配信状況（配信済み・未配信・予定）

### 設定

メッセージ送信と連携の付け外しには、Vercel の環境変数 `ADMIN_API_KEY` が必要です。好きな長い文字列を設定して再デプロイしてください。そのあと、管理画面の「LINE操作キー」に同じ文字列を入れて保存します。キーはその端末のブラウザにだけ保存されます。

LINEで送るメッセージ（プッシュ）は、LINE公式アカウントの月の無料メッセージ数に含まれます。

## 目標値の計算

- 基礎代謝: Mifflin-St Jeor 式（入力があればその値）
- 活動係数: 低い 1.2 / 普通 1.375 / 高い 1.55 / 非常に高い 1.9
- 目標カロリー: 基礎代謝 × 活動係数 ± 300（減量 −300 / キープ ±0 / 筋肉をつける +300）
- たんぱく質: 体重 × 2.0g（キープは1.6g）、脂質: カロリーの25%、炭水化物: 残り
- ビタミン・ミネラル等: 日本人の食事摂取基準（2025年版）の性別・年齢別の値（`src/liff/nutrients.js` の `DRI`）

## データの保存場所

既存アプリと同じ Supabase の `kv_store` に保存します。

- `nutri:<LINEユーザーID>` … プロフィール・食事・体重・水分・目標
- `nutri_photo:<LINEユーザーID>:<slot>` … ビフォーアフター写真（アプリ未連携の人。slot は before / before_side / before_back / after / after_side / after_back）
- `profile_photo:<会員ID>:<slot>` … 連携済みの人の横・後ろの写真（正面はアプリの beforePhoto / afterPhoto）
- `line_log:<LINEユーザーID>` … LINEのやりとり（直近100件、管理画面用）
- `app_login:<token>` … LINEからアプリを開くときの使い捨てトークン
- `nutri_img:<LINEユーザーID>:<食事ID>` … 食事写真のサムネイル
