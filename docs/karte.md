# 顧客カルテ（/karte）

スタッフがトレーニング中にタブレット・スマホで開く顧客管理表です。
元々の顧客スプレッドシートと、TTGYMアプリ・公式LINEの記録を1人1枚のカルテにまとめます。

- 本番: `https://t-tgym-app.vercel.app/karte`
- デモ（サンプルデータ・保存はされません）: `https://t-tgym-app.vercel.app/karte?demo=1`

## 画面

| タブ | 中身 |
| --- | --- |
| 今日の記録（開くと最初にこの画面） | 一番上にトレーニング中のメモ（前回のメモ・注意事項を横に表示。書いた内容は端末に自動で下書き保存）、メニューを選ぶ、体調・痛み、お客様へのコメント、回数券を1回使う、LINEでも送る |
| カルテ | 目標（編集可）、スタッフメモ（注意事項）、成長の変化（はじめて測った日→最新）、前回のセッション、最近の体調・自主トレ（アプリ・LINEの記録）、顧客シートの行 |
| 成長・測定 | 体重・体脂肪率・筋肉量・ウエストなどの推移グラフ（目標の線つき）、定期測定の入力、測定の一覧 |
| ビフォーアフター | 正面・横・後ろの写真を並べて比較、撮影・差し替え |
| 履歴 | 毎回のセッション（メニュー・コメント・メモ・担当）、管理画面で付けたパーソナル記録・コメント |

右上の「一覧を隠す」で、お客様の名前が並ぶ左の一覧をボタン1つで隠せます（その端末では次に開いたときも隠れたまま）。

上部の黒いカードが残り回数券です。±ボタンか数字を押して直接入力できます。2回以下になると赤くなり、一覧の「回数券わずか」にも出ます。

## 顧客スプレッドシートとの連携

TTGYMの顧客シート（`src/karte/store.js` の `DEFAULT_SHEET_URL`）を、カルテを開くたび・「更新」を押すたびに読み直します。
シートは「リンクを知っている全員（閲覧者）」で共有しておく必要があります（読めないときは画面上部に赤い帯が出て、前回読んだ内容で表示します）。

- 名前・フリガナはシートの表記で表示します（アプリ・LINEの名前はフリガナの横に小さく表示）
- 残り回数はシートの値が基準です。カルテでセッションを記録すると1回減り、シートの数字が書き換わったら（回数券の購入など）シートの値に合わせ直します

別のシートを使うときは、以下の手順で設定から変えられます。

1. Google スプレッドシートの「共有」を「リンクを知っている全員（閲覧者）」にする（または「ウェブに公開」）
2. カルテ右上の「設定」→「顧客スプレッドシート」にURLを貼って「読み込む」（CSVファイルでも可。Shift_JISのCSVも読めます）
3. 名前・残り回数などの列の対応を確認して「保存してカルテに反映」

- 見出しの言葉（氏名・フリガナ・残り回数・目標・電話 など）から列を自動で見つけます
- アプリ会員・LINEのお客様とは、電話番号 → 名前（フリガナ）の順で自動でつながります。合わないときはカルテの「顧客シート」→「紐付ける」で選べます
- シートにしかいないお客様もカルテに出ます（「シートのみ」）
- 残り回数は、カルテで増減した値が優先です。シートへの書き戻しはしません
- シートを更新したら、設定でもう一度「読み込む」→「保存」してください

## アプリ・公式LINEとの連携（同じデータを読み書き）

| カルテで | 保存先 | お客様側での見え方 |
| --- | --- | --- |
| 目標・目標体重 | 会員は `profile:<ID>`、LINEだけの人は `nutri:<LINE ID>` の goal | アプリの登録タブ・LINEの「わたしの目標」 |
| メニュー | `data:<ID>:personalLogs`（第◯回） | アプリ・LINEのレポート |
| お客様へのコメント | `data:<ID>:comments`（パーソナル） | アプリ・LINEの「コメント」。チェックでLINEにも送信 |
| セッションした日 | `data:<ID>:sessions` の personalTraining | メンバーシップ +2pt |
| 体重・体脂肪率・筋肉量・周径 | `data:<ID>:growth` | アプリ・LINEの成長グラフ |
| 体力テスト | `data:<ID>:monthly` | 月次測定 |
| 写真 | アプリ・LINEと同じ写真のキー | 目標タブのビフォーアフター |

カルテだけのデータ（お客様には見えません）

- `data:<ID>:karteSessions` … 毎回の記録（スタッフメモ・体調・担当を含む全部）
- `karte:<ID>` … 残り回数券と増減の記録、スタッフメモ（注意事項）、最終来店日
- `global:karteSheet` / `global:karteSheetLinks` … 読み込んだシートと手動の紐付け
- `global:karteMenus` / `global:karteStaff` … 追加したメニューとスタッフ名

`<ID>` は、アプリ会員は会員ID、公式LINEだけの人は `line_<LINE ID>`（LINEのページと同じ）、シートだけの人は `sheet_<行>`。

LINEへの送信には、管理画面と同じ「LINE操作キー」（Vercel の `ADMIN_API_KEY`）を設定画面で入れておきます。
